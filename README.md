# Crumbcloud website

Showcase and online ordering site for Crumbcloud, a fictitious bakery created for a demo.

Static multi-page site built with [Vite](https://vite.dev), deployed on Vercel.

```sh
npm install
npm run dev      # local development
npm run build    # production build in dist/
```

Pages: `/` (cakes), `/order/` (order and payment), `/where/` (shop location), `/contact/` (contact form).
